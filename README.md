# PONERO 견적 도우미 (MVP)

칸막이 시공 사장님이 당근·네이버 등에서 받은 고객 문의를 붙여 넣으면 아래 결과를 만들어 주는 웹페이지예요.

1. 문의 내용 정리: 종류, 길이·높이, 칸 수, 문, 색상, 장소, 일정, 철거 여부
2. 고객에게 되물을 질문 목록
3. 단가표 기준 견적 초안
4. 그대로 복사해서 보낼 수 있는 답장 초안

- 고객에게 자동으로 보내지 않아요. 사장님이 확인하고 직접 보내요.
